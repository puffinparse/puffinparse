What happens to your document and keys
  • Samples are files and outputs published with the benchmark; showing them sends nothing anywhere.
  • Your document goes to the PuffinParse gateway and from there to each provider you picked, which processes it under its own terms and retention policy. The gateway holds it in memory for the upload only: it is not written to disk, stored or logged.
  • Outputs are not stored by the gateway: each poll reads the result from the provider, and the job handle (id, model, time, no content) expires after an hour. On this page they live until you leave or run again.
  • Your keys travel in a request header to the gateway and on to that provider only. The gateway never stores or logs them. This page keeps them in memory for the tab, or in this browser's local storage if you tick "Remember", and never sends them anywhere else.
  • Free tier: Supabase holds your sign-in (email or GitHub account), and we count the model-pages you use per day. Nothing about the document is recorded.
